# NeurIPS 2026 Workshops

An interactive, single-file directory of all 73 accepted NeurIPS 2026 workshop
sub-groups (parent group `NeurIPS.cc/2026/Workshop` on OpenReview).

**Live page:** https://danyaljj.github.io/neurips2026-workshops/

## Columns
- **Workshop** — acronym / name (submission tracks noted as sub-labels)
- **Description** — one-line paraphrased topic summary
- **Deadline** — contributor submission deadline, with a provenance chip:
  - `OpenReview` — confirmed by the live OpenReview submission invitation (`duedate`)
  - `site` — reported only on the workshop's own website
  - `unposted` — no deadline published yet, or the site still shows a prior-year edition
- **Venue** — Sydney (main), Atlanta, or Paris (satellites)
- **Source** — link to the workshop site or OpenReview group

Sort by any column, filter by venue, and search by name/topic. See the notes at the
bottom of the page for per-workshop caveats (stale sites, conflicting dates, etc.).

Data gathered 2026-07-24; deadlines marked `site`/`unposted` are subject to change.
